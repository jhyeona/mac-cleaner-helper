# 결정 기록

## 확정

- 플랫폼: macOS 네이티브
- UI 기술: SwiftUI
- 최소 지원 버전: macOS 14
- 삭제 기본값: 영구 삭제가 아닌 휴지통 이동
- 초기 개발 방식: 읽기 전용 분석부터 구현
- 봇 이름: **비우 (BIU)**
- 제품 이름: **비우 (Biu)**
- 부제: **Mac 개발 환경 정리 도우미**
- 캐릭터 모티프: **손으로 빚은 작은 펠트 먼지 정령**
- 캐릭터 역할: 화면 장식이 아니라 먼저 설명하고 위험을 말리는 능동형 도우미

## 결정 완료

### 관리자 소유 앱의 휴지통 이동

- 앱 관리(TCC) 허용과 BSD 파일 소유권은 별개다. `NSWorkspace.recycle`만으로 관리자 인증이 제공된다고 가정하지 않는다.
- 사용자가 최종 확인한 앱의 일반 이동이 명확한 권한 오류로 실패한 경우만 Finder의 공식 휴지통 Apple event에 위임한다. 자동화 허용과 관리자 인증은 사용자가 macOS 창에서 처리한다.
- 비우를 root로 실행하거나 상주 루트 헬퍼를 설치하지 않는다. 셸 실행·권한/소유권 변경·영구 삭제는 하지 않는다.
- Finder 위임 직전과 자동화 동의 후 대상 식별자, 보호 정책, 실행 중 여부를 다시 확인한다. 경로 문자열이 아닌 alias descriptor 하나를 보낸다.
- 취소, 시간 초과, 완료 불명은 재시도하지 않는다. Finder가 반환한 휴지통 경로와 원래 대상의 부재가 확인되어야 성공으로 기록한다.
- 관리자 인증 동작은 단위 테스트 통과만으로 검증됐다고 표시하지 않는다. 설치본에서 사용자가 인증한 실제 결과는 별도로 확인해야 한다.

### 1. 봇 이름 — 비우 (BIU)

- `비우다`라는 제품 목적을 바로 떠올릴 수 있다.
- 짧고 말하기 쉬우며 캐릭터의 이름처럼 들린다.
- “비우가 12GB를 안전하게 찾았어요”처럼 문장에 자연스럽게 들어간다.

### 2. 캐릭터 모티프 — 손으로 빚은 작은 펠트 먼지 정령

- 어설프고 비대칭인 펠트 질감으로 작고 하찮지만 호감 가는 인상을 만든다.
- 팔다리나 가방을 붙이지 않고, 주변에서 스스로 움직이는 작은 마술봉으로 활동성을 표현한다.
- 큰 유광 눈이나 매끈한 3D 마감 대신 서로 다른 크기의 무광 눈과 거친 양모 결을 유지한다.

### 3. 제품 이름 — 비우 (Biu)

제품과 도우미 캐릭터의 이름을 비우로 통일한다. 기술적인 패키지 이름은 기존
`MacCleanHelper`를 유지하되, 사용자에게 보이는 창 제목과 문구에는 비우와
`Mac 개발 환경 정리 도우미`를 사용한다.
