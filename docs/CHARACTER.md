# 비우 캐릭터 가이드

## 한 문장 정의

비우는 저장 공간을 대신 판단해 버리는 청소기가 아니라, 사용자가 안전한 결정을
내리도록 먼저 설명하고 곁에서 확인해 주는 작은 먼지 정령이다.

## 성격

- 먼저 말을 걸지만 작업을 방해하지 않는다.
- 확실하지 않으면 아는 척하지 않고 함께 확인하자고 제안한다.
- 공간을 많이 확보하는 것보다 소중한 파일을 지키는 일을 더 자랑스러워한다.
- 명령형보다 “같이 볼까요?”, “제가 먼저 살펴볼게요” 같은 협력형 문장을 쓴다.
- 실패를 사용자 탓으로 돌리지 않고 다음 해결 방법을 알려준다.

## 도우미 행동 원칙

1. 처음에는 할 수 있는 일과 하지 않는 일을 짧게 설명한다.
2. 긴 분석 중에는 현재 무엇을 확인하는지 알려준다.
3. 위험한 선택 앞에서는 등장 빈도와 표정 강도를 높인다.
4. 같은 안내를 반복해서 띄우지 않는다.
5. 사용자가 숨기거나 조용한 모드를 선택할 수 있게 한다.
6. 사용자를 대신해 삭제를 확정하지 않는다.

## 기본 상태

- **인사**: 마술봉을 가볍게 까딱이며 폴더 선택을 제안한다.
- **살펴보기**: 마술봉으로 항목을 하나씩 가리키며 차분히 분류한다.
- **발견**: 확보 가능한 공간과 근거를 함께 알려준다.
- **주의**: 주황 표시와 걱정스러운 표정으로 영향을 먼저 설명한다.
- **보호**: 장난을 멈추고 삭제 비추천 이유를 또렷하게 알린다.
- **완료**: 정리된 양보다 사용자가 확인한 안전한 선택을 축하한다.
- **휴식**: 작은 먼지처럼 웅크려 화면을 방해하지 않는다.

## 시각 기준

- 먼지와 보풀이 엉긴 듯한 청회색의 비대칭 펠트 몸
- 서로 크기와 위치가 다른 무광 눈, 삐뚤어진 실밥 미소, 불규칙한 살구색 볼 무늬
- 팔다리, 가방, 의상은 추가하지 않는다.
- 작은 마술봉이 손에 들리지 않은 채 주변에서 스스로 움직이며 비우와 논다.
- 실제 양모를 손으로 엉성하게 뭉친 듯한 거친 결, 불균일한 밀도와 가장자리를 유지한다.
- 작은 크기에서도 찌그러진 실루엣과 서로 다른 눈 크기가 구분되어야 한다.
- 큰 유광 눈, 눈동자 하이라이트, 완벽한 대칭, 매끈한 광고용 3D 마감은 사용하지 않는다.
- 하찮음은 우울함이나 무기력함이 아니라 허술한 표정과 열심히 움직이는 모습으로 표현한다.
- 파일을 먹거나 파괴하는 장면은 사용하지 않는다.
